Base Set 2 è la quarta espansione inglese: 130 carte, uscita il 24 febbraio 2000, composta solo da ristampe di Set Base e Jungle. Non ha un equivalente giapponese ed è stata pensata come nuovo punto d'ingresso al gioco, sostituendo il Set Base negli starter.

## Cosa introduce

Base Set 2 non introduce nessuna carta o meccanica nuova: tutte le statistiche sono identiche agli originali. Le sue novità riguardano la selezione delle carte e la loro rarità.

- **Un unico set d'ingresso**: unisce in un solo set i Pokémon più importanti di Set Base e Jungle, così i nuovi giocatori trovano Blastoise e Wigglytuff nelle stesse buste.
- **Carte escluse dal Set Base (8)**: Machamp, Porygon, Koffing, Ponyta, Clefairy Doll, Devolution Spray, Pokémon Flute, Revive.
- **Carte escluse da Jungle (12)**: Flareon, Jolteon, Vaporeon, Eevee, Vileplume, Gloom, Oddish, Primeape, Mankey, Rapidash, oltre alle versioni Jungle di Electrode e Pikachu, sostituite dalle versioni del Set Base.
- **Rarità rimescolate**: le holo passano a 20 (entrano Clefable, Clefairy, Nidoqueen, Pidgeot, Scyther, Wigglytuff). Kangaskhan, Mr. Mime, Snorlax, Pinsir, Venomoth ed Electabuzz diventano rare senza versione holo.
- **Nuovi mazzi tematici**: Grass Chopper, Hot Water, Lightning Bug e Psych Out mescolano Pokémon dei due set.
- **Olografia Cosmos**: prima volta in un set inglese al posto della Starlight.

## Carte più giocate nei tornei locali

Le carte più giocate di Base Set 2 sono le stesse dominanti di Set Base e Jungle: Professor Oak, Bill, Computer Search, Gust of Wind e i Pokémon di Haymaker. Il peso del set sta nel fatto di averle mantenute legali. Quando il formato Modified (2002) ha escluso Set Base, Jungle e Fossil, le ristampe di Base Set 2 sono rimaste giocabili. ## Mazzi con Base Set 2

Base Set 2 non ha creato archetipi nuovi: ha conservato quelli di Set Base e Jungle e li ha resi giocabili dopo la rotazione del 2002, senza le carte di Fossil. La colonna "Peso nel meta" è una stima basata sul consenso dei giocatori dell'epoca, non su statistiche ufficiali.

| Mazzo | Carte chiave | Cosa cambia con Base Set 2 | Peso nel meta |
| --- | --- | --- | --- |
| Haymaker | Electabuzz, Hitmonchan, Scyther, Energy Removal, Gust of Wind | Resta intatto nel Modified 2002 | Top tier |
| Rain Dance | Blastoise, Pokémon Breeder, Wigglytuff o Mr. Mime | Perde Lapras e Articuno (Fossil), ma anche il suo contro Muk | Top tier |
| Damage Swap / stall | Alakazam, Chansey, Mr. Mime, Pokémon Center | Perde Vileplume (escluso da Base Set 2) | Secondo piano |
| Wigglytuff / Incolore | Wigglytuff, Jigglypuff, Snorlax, Kangaskhan, Energia Doppia Incolore | Invariato | Secondo piano |
| Mazzi tematici | Grass Chopper, Hot Water, Lightning Bug, Psych Out | Mazzi precostruiti per principianti, base per i primi tornei giovanili | Casual |

Nel Modified questi mazzi si sono fusi con le nuove carte: Dark Vileplume e Dark Dragonite di Team Rocket, Erika e Brock di Gym Heroes, Blaine e Sabrina di Gym Challenge.

## Carte più rare

Base Set 2 è stato stampato solo in Unlimited e poco, perché uscito pochi mesi prima di Team Rocket: per questo le sue 20 holo, Charizard in testa, sono più difficili da trovare in ottime condizioni delle holo Unlimited di Set Base.

| Carta / variante | Perché è rara |
| --- | --- |
| Charizard 4 holo | La carta di punta del set, ricercata soprattutto in condizioni gradate alte |
| Altre holo (Blastoise, Venusaur, Scyther, Wigglytuff, Clefable, Nidoqueen, Pidgeot) | Olografia Cosmos invece della Starlight dei set originali |
| Holo di carte Jungle (Clefable, Nidoqueen, Pidgeot, Scyther, Wigglytuff) | Stessa illustrazione di Jungle ma olografia Cosmos e numerazione /130 |
| Wartortle 63 timbro W | Promo della rivista Top Deck |

Le rare non holo (Kangaskhan, Mr. Mime, Snorlax ecc.) valgono molto meno: in Jungle esistevano anche in versione holo. [Base Set 2 su Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Base_Set_2_(TCG))
